# Project Charter

## Mission

Restore Ubiq as a credible, community-owned EVM network with dependable
infrastructure, excellent basic tooling, and a small ecosystem of products
that people can actually use.

## Initial audiences

1. Existing UBQ holders, miners, node operators, and contributors.
2. Solidity developers who value a stable, low-cost independent network.
3. Small applications that benefit from inexpensive permanent settlement.

## Proposed promise

Ubiq is a durable, independent Proof-of-Work EVM chain: fairly launched,
community maintained, predictable, and uncomplicated.

## In scope

- protocol and client maintenance;
- node, RPC, explorer, testnet, faucet, and monitoring infrastructure;
- wallet and developer onboarding;
- bridge, exchange, and wrapped-asset foundations;
- documentation, governance, security, and contributor operations;
- a coherent public identity and communications cadence.

## Out of scope for the first 90 days

- a consensus migration;
- speculative tokenomics redesign;
- numerous new dApps;
- paid promotion before core infrastructure is dependable;
- claims about investment returns or guaranteed adoption.

## Definition of success

At the end of the first cycle, a new developer can discover Ubiq, add it to a
wallet, obtain test funds, deploy a contract, inspect it, and find help without
using stale instructions or private knowledge.
